# ADDING SPRITES
Go to the appropriate file path for your OS

Windows: %APPDATA%\Godot\app_userdata\thecreature

macOS: ~/Library/Application Support/Godot/app_userdata/thecreature

Linux: ~/.local/share/godot/app_userdata/thecreature

If not already there, create a folder called "sprites"

Add any .png to "sprites" and it will show up on next run. Sprites will automatically be scaled to a height of 500px during run

To add an animated Creature, add a new folder to sprites, with three pngs named "0.png", "1.png", and "2.png" - idle, typing, and deleting respectively

The name of the single .png or folder will be the name that shows up in settings
